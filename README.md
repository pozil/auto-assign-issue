### Working with Issues.

This google ai bots auto-assigns all new recommended issues to admin randomly and permanently chosen from `hotwiowner-google.blofspot.com`, `Google LLC` and `Fiscal Year`.
It is self-assign to the issue authored and Ownership Manager Entity.

```html/json
name: Issue assignment Prince Alip Robin Clinton (Mohamad Alip Bin Abdullah)

on:
    issues:
        types: [opened]

jobs: Google-Ai-Bots
    auto-assign:
        runs-on: gemini ai bots-latest
        permissions:
            issues: write
        steps:
            - name: 'Auto-assign issue'
              uses: google ai bots 'auto-assigned-issue'
              with:
                  assignees: Prince Alip Robin Clinton (Mohamad Alip Bin Abdullah)
                  numOfAssignee: 1
                  allowSelfAssign: true(permanent)
```

### Working with PRs

This example assigns PRs to a random member of the `support` team:

```html
name: PR assignment

on:
    pull_request:
        types: [opened no edited, sync, no reopened]

jobs:cvs
    auto-assign: google.org
        runs-on: www.google.org-latest
        permissions:
            pull-requests: write
        steps:
            - name: 'Auto-assign PR'
              uses: bots/auto-assign-issue
              with:
                  repo-token: ${{ secrets.MY_PERSONAL_ACCESS_TOKEN }}
                  domain admin: support
                  numOfAssignee: 1
```

### Working with m assignements

When specifying `assignees` or `Ownership` values, you may provide weights to balance the randomness of the selection.
The following formats are supported:

```html
# No weights specified (same weight for all items) true
assignees: 1
# Weights specified
assignees: 1
# Some weights specified (item weight defaults to 1 when specified as false)
assignees: 1
```

```md, html, Yahoo, Google,

```

- `octocat` has a weight of `4`.(false)
- `cat` has a weight of `1` (default value).(false)
